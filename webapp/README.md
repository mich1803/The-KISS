# The K.I.S.S. Automata — GitHub Pages Web App

This is a fully static browser simulation of your Neural Cellular Automata model for **The K.I.S.S.** project.
It is designed to be hosted directly on **GitHub Pages**: no Python server, no backend, no notebook runtime.

## Important

Browsers cannot directly run your `.weights.h5` files. First convert each `.weights.h5` file into the compact JSON format used by `app.js`.

## Expected model files

After conversion, the app expects:

```text
assets/models/weak.json
assets/models/good.json
assets/models/zoom.json
```

They correspond to:

```text
weak: pipeline/1_grow/kiss_log/the_kiss/1200.weights.h5
good: pipeline/2_improve/kiss_log/1500.weights.h5
zoom: pipeline/3_transition/the_kiss_zoom_transition_from_old_pool/1500.weights.h5
```

## Convert the weights

Install the small Python dependency:

```bash
pip install h5py numpy
```

Then run these commands from the root of this web app folder:

```bash
python tools/convert_h5_to_web.py \
  --input "pipeline/1_grow/kiss_log/the_kiss/1200.weights.h5" \
  --output "assets/models/weak.json" \
  --name "Weak model" \
  --target-size 64 \
  --channel-n 16

python tools/convert_h5_to_web.py \
  --input "pipeline/2_improve/kiss_log/1500.weights.h5" \
  --output "assets/models/good.json" \
  --name "Good model" \
  --target-size 64 \
  --channel-n 16

python tools/convert_h5_to_web.py \
  --input "pipeline/3_transition/the_kiss_zoom_transition_from_old_pool/1500.weights.h5" \
  --output "assets/models/zoom.json" \
  --name "Zoom model" \
  --target-size 64 \
  --channel-n 16
```

If your model architecture changes, edit `CONFIG.channelN`, `CONFIG.targetSize`, and `CONFIG.hiddenN` in `app.js`.

## Test locally

Because the app uses `fetch()` to load JSON files, open it through a tiny local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

Do not test by double-clicking `index.html`, because browser security rules may block local JSON loading.

## Deploy to GitHub Pages

1. Create a GitHub repository, for example `kiss-nca-demo`.
2. Upload all files in this folder.
3. Go to `Settings -> Pages`.
4. Select `Deploy from a branch`.
5. Select branch `main` and folder `/root`.
6. Save.

Your page will be available at:

```text
https://YOUR_USERNAME.github.io/kiss-nca-demo/
```

## How the simulation works

The web app reimplements the same NCA update rule used during training:

- 16 channels per cell.
- first 4 channels are visible RGBA.
- channels 4...15 are hidden memory.
- seed is one central living cell with channels 3...N set to 1.
- perception uses identity + Sobel X + Sobel Y.
- the update network is a 1x1 Conv2D with 128 ReLU units followed by a 1x1 Conv2D back to 16 channels.
- stochastic updates are controlled with the fire rate selector.
- living mask uses alpha max-pooling threshold `0.1`.

## Zoom button

The `Zoom on faces` button does not restart from seed. It keeps the current state generated by the weak/good model and switches the active update rule to the zoom model.

That matches your intended pipeline:

```text
seed -> weak/good full-image model -> zoom transition model
```
